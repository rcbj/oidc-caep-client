◆ CAEP Demo oidc-caep-client · in-browser public client

Identity provider

Not configured

Point this app at any OpenID Connect Core 1.0 provider. It runs entirely in this browser as a public client (no client secret) and configures itself from the provider's metadata document.

Security

Advanced OIDC settings

The stream is created with the signed-in user's access token and polled from this browser (RFC 8936). A browser cannot receive pushed events.

Events to request

Register these with your IdP (public client, token_endpoint_auth_method none)

OpenID Connect + Shared Signals

Continuous access, in real time.

Sign in through your identity provider. This page keeps your tokens, refreshes them before they expire, and listens for CAEP events that can change or end your session while you're using it.
